# Left Right

En modern webbapp byggd med React, TypeScript och Vite.

## Kom igång

```bash
npm install
npm run dev
```

Öppna adressen som Vite visar i terminalen.

## Kommandon

- `npm run dev` – starta utvecklingsservern
- `npm run build` – skapa en produktionsbuild
- `npm run lint` – kontrollera koden
- `npm run preview` – förhandsgranska produktionsbuilden
